Vanille pour chocolat : définir le besoin technique

Pour une utilisation dans le chocolat, la taille visuelle d’une gousse entière est souvent moins importante que le profil aromatique, l’état de la matière, le niveau d’humidité, le format et la régularité du lot. Nous recommandons donc une demande basée sur votre recette et votre procédé.

Chocolat

Incorporation dans recettes chocolatées, ganaches, fourrages et préparations aromatiques.

Extraction

Matière destinée à des procédés d’extraction et de transformation selon spécification.

Échantillon

Permet de tester l’arôme, le comportement dans le procédé et le résultat final.

Lot

Les caractéristiques sont confirmées avant commande selon disponibilité réelle.

Informations utiles pour une offre Cuts

  • usage final : chocolat, extraction ou autre transformation ;
  • quantité par commande et fréquence ;
  • format souhaité ;
  • humidité ou paramètres analytiques si requis ;
  • conditionnement ;
  • destination et exigences documentaires.

Qualité et traçabilité

Les documents qualité disponibles et informations de traçabilité sont fournis sur demande selon le lot. Pour les lots certifiés, une vérification du fournisseur et/ou des producteurs concernés peut être organisée selon les documents et le périmètre de certification disponibles.

Le choix d’une vanille pour chocolat doit être fait selon le procédé réel de l’acheteur, pas uniquement selon une appellation commerciale.
